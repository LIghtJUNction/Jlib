[h1]Jlib — 高性能共享前置库[/h1]
Jlib 是从 Peter Han 的 PLib 4.25 深度演进的下一代《缺氧》共享库，为下游 Mod 提供标准化前置。

[b]核心功能全集[/b]
* PLibCore：反射增强 (PDetours 快速委托)、补丁管理 (PPatchTools / PPatchManager / PTranspilerTools)、线程对象池 (PThreadLocalPool)、PO 翻译 (PLibLocalization)、TMP 字体补丁与跨 Mod 注册表 (PRegistry)。
* PLibOptions：全功能 Mod 配置选项界面 (POptions)，支持全类型控件、分类折叠、重启提醒与动态热刷新。
* PLibUI：声明式轻量级 Unity UI 引擎，包含全套标准控件、4 大自适应布局系统与可拖拽浮动弹窗。
* PLibActions / Buildings / Lighting / Database / AVC：自定义按键映射、建筑注册与管线端口、多边形光照、法典成就注入与自动更新检查。
* Jlib.Runtime：严格 ABI 1 握手、零依赖引导合约 (JlibContract)、原生库 Mono P/Invoke 动态重定向 (ReplaceNativeLibrary / ReplaceSimDll)、沙盒化资源读取 (ModResources) 与游戏组件热替换。

[b]独家特性：动态接口统计与 Harmony 补丁排序诊断器[/b]
* 动态无硬编码枚举：运行时反射实时扫描所有模块与公开 API，随 Mod 更新自动同步。
* 统计接口调用次数与来源 Mod：精准记录各接口调用量，自动回溯堆栈定位发起调用的下游 Mod。
* 补丁覆盖流水线全景：清晰列出所有受挂钩方法的 Prefix、Transpiler 与 Postfix 覆盖链路。
* 拖拽与交互排序：在配置界面中唤出浮动面板，点击 [▲ 提前] 或 [▼ 延后] 即可实时重排补丁优先级，即刻化解 Mod 冲突！
* 全功能 Debug：一键开启详细日志追踪并支持导出完整快照至 Player.log。

[b]使用与开发[/b]
* 玩家：订阅并在 Mod 列表排在依赖它的 Mod（如 CycleTrim、OniMcp）上方，重启游戏。
* 开发者：NuGet 包 LIghtJUNction.Jlib (net48 / netstandard2.1)，ExcludeAssets="runtime"，禁止打包 Jlib.dll。
